# Shell completion

`outsystems-cli` ships with completion scripts for **bash**, **zsh**, **fish**,
and **PowerShell**, generated by the built-in `completion` command. Once set up,
your shell will complete command names, subcommands, and flags (e.g.
`outsystems-cli app<TAB>` → `applications`).

Generate a script for your shell with:

```sh
outsystems-cli completion <bash|zsh|fish|powershell>
```

Run `outsystems-cli completion <shell> --help` for the exact, up-to-date
instructions for your platform. The steps below cover the common cases.

## Bash

Completion requires the [`bash-completion`](https://github.com/scop/bash-completion)
package (v2 is recommended).

=== "Current session"

    ```sh
    source <(outsystems-cli completion bash)
    ```

=== "Linux (every session)"

    ```sh
    outsystems-cli completion bash > /etc/bash_completion.d/outsystems-cli
    ```

=== "macOS (every session, Homebrew)"

    ```sh
    outsystems-cli completion bash > $(brew --prefix)/etc/bash_completion.d/outsystems-cli
    ```

Start a new shell for the change to take effect.

## Zsh

If completion is not already enabled, enable it once:

```sh
echo "autoload -U compinit; compinit" >> ~/.zshrc
```

=== "Current session"

    ```sh
    source <(outsystems-cli completion zsh)
    ```

=== "Linux (every session)"

    ```sh
    outsystems-cli completion zsh > "${fpath[1]}/_outsystems-cli"
    ```

=== "macOS (every session, Homebrew)"

    ```sh
    outsystems-cli completion zsh > $(brew --prefix)/share/zsh/site-functions/_outsystems-cli
    ```

Start a new shell for the change to take effect.

## Fish

=== "Current session"

    ```sh
    outsystems-cli completion fish | source
    ```

=== "Every session"

    ```sh
    outsystems-cli completion fish > ~/.config/fish/completions/outsystems-cli.fish
    ```

## PowerShell

=== "Current session"

    ```powershell
    outsystems-cli completion powershell | Out-String | Invoke-Expression
    ```

=== "Every session"

    Append the generated script to your PowerShell profile:

    ```powershell
    outsystems-cli completion powershell >> $PROFILE
    ```

!!! tip
    Add `--no-descriptions` to any of the commands above to generate a script
    without completion descriptions, if your shell setup prefers terse output.
