## outsystems-cli modules version-get

Get the details of a specific module version

### Synopsis

Calls GET /modules/{ModuleKey}/versions/{ModuleVersionKey}/.

```
outsystems-cli modules version-get <module-key> <module-version-key> [flags]
```
