## outsystems-cli version

Show the LifeTime version and supported Platform Server version

### Synopsis

version calls GET /version/ and prints the LifeTime version information,
including the installed LifeTime version and the supported Platform Server
version.

```
outsystems-cli version [flags]
```

### Options

```
  -h, --help   help for version
```
