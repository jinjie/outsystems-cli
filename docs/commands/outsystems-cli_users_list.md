## outsystems-cli users list

List users

### Synopsis

Calls GET /users/ and returns all users.

```
outsystems-cli users list [flags]
```

### Options

```
  -h, --help                        help for list
      --include-application-roles   include application roles
      --include-inactive            include inactive users
      --include-teams               include teams each user belongs to
```
